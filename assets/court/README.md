# Court player assets

- `player.glb`: Quaternius Universal Base Characters (male), CC0. Vertex
  colours mark jersey (R), shorts (G), shoes and socks (B).
- `ual_standard.glb`: Quaternius Universal Animation Library, Standard tier,
  CC0. Same skeleton as the player (idle, walk, jog, sprint, jump).
- `dribble_run`, `slide_l`, `slide_r`, `stance`, `jumpshot`, `layup`: cut
  from the CMU Graphics Lab Motion Capture Database (mocap.cs.cmu.edu),
  subjects 6, 76, 102 and 124. CMU places no restrictions on use.
- Built by `tools/court_assets/build.py` (Blender, headless).
